# ❄️ منظومة سِـوار (SWAR) لإدارة وجرد مخزون الأغذية المجمدة

تطبيق ويب متكامل، فائق السرعة، ومجاني 100% لإدارة ومتابعة وجرد مخزون الأغذية المجمدة (ستربس، بانيه، برجر، خضروات، مقبلات، لحوم، أسماك) باللغة العربية بالكامل وبدعم كامل للاتجاه من اليمين إلى اليسار (RTL)، ومصمم خصيصاً للعمل بسلاسة على الهواتف المحمولة أثناء التواجد الميداني داخل غرف وثلاجات التجميد.

---

## 🚀 المميزات والخصائص الرئيسية

1. **إدارة المنتجات والأصناف (CRUD كامل):**
   - إضافة وحذف وتعديل الأصناف المجمدة.
   - تحديد التصنيف (دواجن، لحوم، أسماك، مقبلات، خضار وفواكه مجمدة).
   - تحديد وحدة القياس (كيس، كرتونة، طبق، علبة، كجم) ومكان الحفظ (رقم الفريزر / الرف).
   - ضبط مستويات التنبيه الذكية: **الحد الأدنى الحرج** و**الحد الآمن للمخزون**.

2. **سجل الجرد الذكي (Stock Audit History):**
   - فتح سجل الجرد المفصل لأي منتج بلمسة واحدة.
   - تسجيل عمليات جرد جديدة مع حساب الفارق التلقائي (عجز 🔻 / زيادة 🔺 / ثبات ➖).
   - تاريخ وتوقيت الجرد الدقيق واسم القائم بالجرد وملاحظات الوردية.
   - إمكانية تعديل أو حذف أي حركة جرد سابقة.

3. **المؤشرات اللونية الذكية (Smart Color-Coded Indicators):**
   - 🔴 **أحمر:** كميات حرجة أو نفاد تام للمخزون (أقل من أو يساوي الحد الأدنى).
   - 🟡 **أصفر:** مخزون متوسط يقترب من النفاد ويحتاج لطلب توريد قريباً.
   - 🟢 **أخضر:** مخزون كافي وآمن ومطابق لمعدلات التشغيل.
   - ⏱️ **مؤشر حداثة الجرد:** تمييز الأصناف التي لم تُجرد منذ فترة وتتطلب إعادة الفحص.

4. **وضع الجرد السريع للهواتف (Quick Mobile Audit Mode):**
   - واجهة مخصصة وسريعة للجرد المتسلسل صنفاً تلو الآخر بأزرار لمس كبيرة مناسبة للاستخدام في البرودة.
   - شريط تقدم تفاعلي مع نغمات تأكيد فورية.

5. **لوحة المؤشرات والفلترة الفورية (Dashboard & Filters):**
   - بطاقات إحصائيات تفاعلية قابلة للنقر لفلترة الأصناف (النواقص، المتأخرة، المكتملة).
   - بحث فوري بالاسم، مكان الفريزر، أو الملاحظات.
   - ترتيب ديناميكي حسب الأولوية، الأقل كمية، الأقدم في تاريخ الجرد، أو أبجدياً.

6. **التقارير والتصدير والنسخ الاحتياطي:**
   - تصدير كشف المخزون المحدث لملف Excel / CSV باللغة العربية (UTF-8 with BOM).
   - طباعة تقرير جرد رسمي منسق أو حفظه بصيغة PDF.
   - تحميل واستعادة نسخ احتياطية كاملة (JSON) بضغطة زر وبدون أي خوادم مدفوعة.
   - حفظ تلقائي فوري في الذاكرة المحلية للمتصفح (LocalStorage) يعمل بدون اتصال بالإنترنت (Offline-Ready).

## 💻 طريقة التشغيل محلياً (Local Setup)

### المتطلبات:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### خطوات التشغيل:
1. افتح موجه الأوامر (Terminal / Command Prompt) في مجلد المشروع:
   ```bash
   cd c:\Users\iamzy\Music\ddd
   ```
2. ثبّت الحزم والتبعيات (في حال لم تكن مثبتة):
   ```bash
   npm install
   ```
3. شغّل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```
4. افتح الرابط في المتصفح:
   ```
   http://localhost:3000
   ```

## 🌐 طرق النشر والاستضافة المجانية 100% (Zero-Cost Deployment)

التطبيق عبارة عن Single Page Application (SPA) ولا يحتاج لخوادم خلفية أو قواعد بيانات مدفوعة، ويمكنك نشره مجاناً مدى الحياة عبر إحدى الطرق التالية:

### الخيار 1: النشر بنقرة واحدة على Vercel (موصى به - مجاني 100%)
1. ارفع المشروع إلى حسابك على [GitHub](https://github.com).
2. ادخل على [Vercel.com](https://vercel.com) وسجل الدخول مجاناً.
3. اضغط على **"Add New Project"** واختر المستودع (Repository).
4. اضغط **Deploy** وستحصل على رابط عالمي مجاني فوري (مثال: `https://swar-frozen.vercel.app`).

### الخيار 2: النشر على Netlify (مجاني 100%)
1. ادخل على [Netlify.com](https://netlify.com).
2. اسحب مجلد `dist` بعد تشغيل أمر البناء `npm run build` إلى صفحة Netlify Drop، أو اربطه بـ GitHub.
3. سيعمل الموقع فوراً برابط مجاني دائم.

### الخيار 3: النشر على GitHub Pages
1. في ملف `vite.config.js`، أضف السطر: `base: './',`
2. نفّذ أمر البناء:
   ```bash
   npm run build
   ```
3. ارفع محتويات مجلد `dist` إلى فرع `gh-pages` في مستودع GitHub الخاص بك.

## 📱 التثبيت كتطبيق هاتف (PWA / Home Screen)
يمكن لمسؤولي غرف التبريد فتح رابط الموقع على هواتفهم (Chrome على Android أو Safari على iOS) والضغط على:
- **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**
- سيظهر التطبيق كأيقونة تطبيق مستقل سريع يعمل بملء الشاشة بدون شريط المتصفح.
